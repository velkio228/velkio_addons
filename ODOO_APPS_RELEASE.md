# Odoo Apps presentation handoff

The Precision Velkio logo appears on both banners, index headers/footers and the
relevant backend brand area. App icons are module-specific: a storefront and sync
image for WooCommerce, and an accounting ledger image for TallyPrime. Module code retains
its synchronization behavior. Versions are 19.0.1.0.1 (WooCommerce) and
19.0.1.2.1 (TallyPrime).

## Layout reference

The structure was adapted from the Shopify EPT 20.0 listing supplied by the user:
https://apps.odoo.com/apps/modules/20.0/shopify_ept

The reference informed the opening summary cards, capability groups, direction
coverage cards, documentation area and support hierarchy. Text, images and claims
remain specific to Velkio; third-party testimonials and commercial promises were
not imported.

## Local viewing

Both `static/description/index.html` files include inline layout styles and can
be opened directly without Bootstrap, internet access or a preview wrapper.
Use Ctrl+0 to reset browser zoom to 100%. Layout is bounded and centered.

## What is prepared

- English, script-free description fragments with local images and email support.
- Features, sync coverage, requirements, six setup steps, workflow, troubleshooting,
  FAQs, data-exchange scope and release information.
- Six existing Tally demonstration screenshots with explanatory captions.
- Original selected logo and branded illustrated banners in `artwork/branding/`.
- Regular module directories and an installable ZIP generated by
  `python3 tools/package_apps.py`. The package resolves the Tally symlink into
  real files so its contents are included.

## Rebuild and check

```bash
python3 tools/build_app_presentation.py --module woo --output velkio_woocommerce_connector/static/description
python3 tools/build_app_presentation.py --module tally --output velkio_tally_integration/static/description
python3 tools/check_app_presentation.py velkio_woocommerce_connector velkio_tally_integration
python3 tools/package_apps.py
```

The Tally output resolves outside this workspace and may require filesystem
permission. The legacy WooCommerce `generate_assets.py` delegates to the shared
builder. Artwork is copied from approved files; it is not regenerated.
